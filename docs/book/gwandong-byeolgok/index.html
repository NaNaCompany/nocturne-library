변환·수정 내역

  • 공유마당의 TXT 응답 원시 gzip 및 압축 해제 바이트를 별도 보존했다. 수록용 TXT는 UTF-8 BOM 제거, CRLF/CR를 LF로 정규화했다. JSON은 비어 있지 않은 원문 각 행을 하나의 읽기 단락으로 옮겼다. 원문의 한자·병기된 독음·옛한글 유니코드 자모·어휘·철자는 변경하지 않았다. 번역·해설은 추가하지 않았다.
