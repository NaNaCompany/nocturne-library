# 이인직 작품 원전 및 전사 권리 기록

검토일: 2026-10-28. 이 자료 묶음은 공개 수록이 가능한 원전 전사와 추가 검토가 필요한 전사를 구분한다. `metadata.json`의 `status: eligible`만 앱 수록 대상으로 사용한다.

**원작층:** 이인직(1862–1916)은 1916년 11월 25일 사망했다. 발표된 원작은 한국의 사후 보호기간이 만료되었고, 1906–1908년에 발표된 원작은 미국의 오래된 공표 저작물 기준에도 해당한다. 현대 번역·주석·교과서 분석문·후대 교주본은 이 판단에 포함하지 않는다.

공식기관 근거:

- [한국학중앙연구원, 이인직](https://encykorea.aks.ac.kr/Article/E0045632): 생몰일 및 작품 발표 경위.
- [한국학중앙연구원, 혈의 누](https://encykorea.aks.ac.kr/Article/E0063484): 1906년 발표, 1907년 단행본, 후속 작품 관계.
- [한국학중앙연구원, 치악산](https://encykorea.aks.ac.kr/Article/E0058373): 상편 1908년 이인직, 하편 1911년 김교제.
- [문화체육관광부, 저작권이 만료된 저작물](https://www.mcst.go.kr/site/s_policy/copyright/question/question11.jsp): 보호기간 만료 저작물의 자유 이용 설명.

기관 자료는 사실 확인 자료로만 사용했다. 기관의 현대 해설문이나 사진을 책 본문에 수록하지 않았다.

**전자전사층:** 실제 가져온 HTML 각 페이지 하단에서 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 링크를 확인했다. 원작의 퍼블릭 도메인 지위와 별도로, 위키문헌 기여자의 전사·편집에 보호되는 기여가 존재하는 범위에는 이 라이선스를 적용한다. 상업적 복제·재배포·변경이 허용되며, 저작자표시·라이선스 링크·변경 표시·동일조건변경허락을 지킨다. 퍼블릭 도메인인 원작 자체에 새로운 독점권을 주장하지 않는다.

권장 앱 귀속문:

> 원작 이인직(1862–1916), 퍼블릭 도메인. 전사·편집 한국어 위키문헌 기여자, CC BY-SA 4.0. 위키문헌 고정판 및 각 스캔 페이지의 편집 이력을 출처에서 확인할 수 있습니다. HTML 탐색 요소와 스캔 쪽번호를 제거하고 문단을 JSON으로 변환했습니다. 원철자를 유지했습니다.

이 귀속문, 각 책의 원문·고정판·이력 링크, 라이선스 링크를 앱의 책별 출처 및 권리 화면에 제공해야 한다. 이 라이선스 대상인 변형 전사 파일은 CC BY-SA 4.0으로 재배포한다. 같은 앱에 함께 실린 독립적인 코드나 다른 책 전체에 이 라이선스를 확장한다고 표시하지 않는다.

## 고정판·기여자·원시 자료

- `raw/*.parse.json`: 가져온 시점의 전체 렌더링 HTML, 상위 revision, 원문 위키텍스트, 절 목록.
- `raw/*.html`: 상위 고정판 HTML과 실제 하단 라이선스 링크.
- `raw/*.history*.json`: 상위 문서의 전체 revision 이력과 기여자 기록.
- `scan-pages.json`: 실제 전사된 스캔 **289쪽**의 제목, 개별 revision, 고정판 URL, 편집 이력 URL, 기여자 목록.
- `raw/scan-pages-batch-*.json`: 스캔 하위 페이지별 최신 고정 revision의 전체 위키텍스트와 기여자 API 응답. 상위 `oldid`만으로 끼워넣은 하위 페이지 내용이 고정된다고 간주하지 않았다.
- `sources.json`: 수집 시각과 URL.
- `hashes.json`: 원시 응답과 생성물의 SHA-256 및 바이트 크기.

끼워넣기 본문은 수집 시점 응답의 해시로 고정한다. 하위 페이지 목록은 동일 시점에 별도로 고정한 revision 및 전체 기여자 목록을 보존한다. 이 작업은 원본 인쇄본의 모든 글자를 수동 대조 교정했다는 뜻이 아니다. 스캔 기반 전사 자료의 오탈자가 남을 수 있다.

변경 사항: HTML 메뉴·출처 배너·라이선스 배너·쪽번호를 독서 본문에서 제거했다. HTML 엔티티를 문자로 변환했다. 서식 공백과 줄바꿈을 정리하고 문단 순서를 유지하여 JSON 및 UTF-8 TXT로 저장했다. 번역·현대어 윤문·분석문을 추가하지 않았다.

## 공개 수록 보류 자료

- `held/eunsegye.json`, `.txt`: 위키문헌 고정판 399814의 현전 상권 후보 전사. 현대 맞춤법 층의 원전·현대 편집층 출처가 확인되지 않았다. **수록 보류.** 공식 [은세계 항목](https://encykorea.aks.ac.kr/Article/E0042839)은 현재 상권만 전한다고 설명하므로 단권 완결본이라고 표시하지 않는다.
- `held/gwiui-seong.json`, `.txt`: 위키문헌 고정판 120254의 제1–20장 후보 전사. 현대 맞춤법 전사층의 외부 원전·현대 편집층 출처가 확인되지 않았다. **수록 보류.**
- `raw/chiaksan-lower.*`: 김교제 하편. 공식기관에서 사망연도가 확정되지 않아 한국 내 사후 보호기간 만료를 단정하지 않았다. 1911년 발표라는 사실이나 미국에서의 상태만으로 한국 내 권리 문제가 해결된다고 간주하지 않는다. **수록 보류.**

현대 전사 후보의 위키문헌 기본 CC 표시는 외부의 무단 전재를 치유하는 보증이 아니다. 이 후보들은 공개 앱 산출물에 복사하지 않는다.

## 공유마당 비교 자료

`raw/gongu-hyeorui-nu.html`은 한국저작권위원회의 [혈의 누 자료](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200019&wrtSn=9001127)이며 실제 HTML의 라이선스 이미지 대체텍스트가 `자유이용 만료`임을 확인했다. `raw/gongu-hyeorui-nu-download.html`과 `raw/gongu-hyeorui-nu.txt`는 같은 자료의 공식 다운로드 응답을 보존한 것이다. 현재 독서 본문은 공유마당 TXT로 바꾸지 않고 위키문헌 스캔 원철자 전사를 사용한다. 공유마당 자료에 대한 확인을 위키문헌의 다른 현대 전사본 권리 보증으로 확대하지 않는다.
